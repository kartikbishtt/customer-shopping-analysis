# Customer Shopping Analysis

An exploratory data analysis project examining customer shopping behavior, purchasing patterns, and factors associated with customer spending.

## Project Overview

This project analyzes a customer shopping behavior dataset using Python and Pandas to identify patterns in purchasing behavior, customer demographics, product categories, payment methods, shipping preferences, discounts, and purchase frequency.

## Dataset

The dataset contains **3,900 customer purchase records** with information including:

- Customer demographics
- Items purchased
- Product categories
- Purchase amount
- Location
- Size and color
- Season
- Review ratings
- Subscription status
- Shipping type
- Discount and promotional code usage
- Previous purchases
- Payment method
- Purchase frequency

## Analysis

The analysis explores:

- Customer demographics
- Product and category purchasing patterns
- Purchase amounts
- Customer review ratings
- Subscription behavior
- Shipping preferences
- Discount and promotional code usage
- Payment methods
- Previous purchase behavior
- Purchase frequency
